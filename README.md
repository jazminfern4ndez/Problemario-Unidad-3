# Problemario de Programación Orientada a Objetos

Este repositorio contiene los programas correspondientes a las **Unidades 3 y 4** del curso de **Programación Orientada a Objetos**, desarrollados en **Java** utilizando **IntelliJ IDEA**.

Cada carpeta contiene el código fuente del ejercicio y una **captura de pantalla con la salida del programa**.

---

## 🧩 Unidad 3

### 📘 3.1 Compra
- Carpeta: `Unidad 3/3.1/Compra`
- Contiene el programa que gestiona compras y la captura `salida compra.png`.

### 📗 3.2 Empresa Agrícola y Villanos
- Carpetas: `Unidad 3/3.2/Empresa_Agricola` y `Unidad 3/3.2/Villanos`
- Incluyen programas que aplican conceptos de **composición y agregación**.

### 📙 3.3 Figuras
- Carpeta: `Unidad 3/3.3/Figuras`
- Programa sobre clases y herencia de figuras geométricas.
- Captura: `salida figuras.png`.

### 📒 3.4 Villanos con Interfaz
- Carpeta: `Unidad 3/3.4/Villanos_Interfaz`
- Ejercicio sobre el uso de **interfaces** en Java.
- Captura: `salida villanos interfaz.png`.

### 📔 3.5 Fútbol y Librería
- Carpetas: `Unidad 3/3.5/Futbol` y `Unidad 3/3.5/Libreria`

---

## 💡 Unidad 4

### 🧠 Excepción Figuras
- Carpeta: `Unidad 4/Excepcion_Figura`
- Programa que implementa el **manejo de excepciones** en clases relacionadas con figuras geométricas.
- Captura: `excepcion.png`.
